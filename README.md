
🤖 AI Resume Analyzer

An AI-powered web application that analyzes resumes and provides useful feedback to help improve them.

✨ Features

- 📄 Upload PDF resumes
- 📊 Resume scoring
- 💪 Detect skills
- ⚠️ Find missing skills
- 💡 Get improvement suggestions
- 🤖 Resume analysis engine
- 📱 Responsive design
- 🌐 Frontend + Python backend

🛠️ Technologies

Frontend

- HTML5
- CSS3
- JavaScript

Backend

- Python
- Flask
- Flask-CORS
- PyPDF2

📊 Score + Skills + Suggestions

🎯 Resume Analysis

The analyzer currently checks for technical skills such as:

- Python
- Java
- JavaScript
- HTML
- CSS
- SQL
- Machine Learning
- Data Science
- Git
- GitHub

It then generates:

- Resume score
- Detected skills
- Missing skills
- Improvement suggestions
